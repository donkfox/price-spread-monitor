# UI Design Reference

The installed Open Design handoff is located at `design/CEO/`.

Use these files as the visual source of truth when implementing or revising the desktop UI:

- `design/CEO/index.html`: exported reference screen
- `design/CEO/DESIGN-HANDOFF.md`: implementation and responsive contract
- `design/CEO/DESIGN-MANIFEST.json`: machine-readable screen, token, interaction, and viewport checklist

Preserve the current product's real workflows and data. Apply the reference's visual hierarchy, typography, spacing, color tokens, component states, and responsive behavior without copying prototype-only labels or unrelated example content.
